# Evidencias del laboratorio

Esta carpeta guarda las salidas de terminal que respaldan el entregable
`docs/DAE_Semana_12_Extra_Fernando_Correa.docx`.

- `*-limpio.txt`: salida de la suite sin códigos ANSI, capturada con Node para conservar UTF-8.
- `*.json`: reporte JSON de Vitest (conteos y nombres de pruebas).
- `*-resumen.txt`: extracto usado en las figuras del entregable.
- `14-examctl-comandos.txt` y `15-cors-check.txt`: transcripciones del cliente sin pantalla.

Los archivos `.txt` sin sufijo `-limpio` son capturas crudas hechas con la redirección de PowerShell; la consola de
Windows puede mostrar caracteres de reemplazo en los acentos. La versión limpia equivalente es la que se cita en el
documento. Los reportes `.json` y los resúmenes no tienen ese problema.
